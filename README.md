# Please Stop

Please Stop is a tiny Minecraft mod idea for builders who are tired of creative flight drifting past the exact block they meant to place.

Current behavior:

- Fabric-first client mod.
- Display name: `Please Stop`.
- Mod id: `please_stop`.
- Native settings screen (`M`), keybinds, and persistent local config.
- Creative Flight Assist (`V`) with vanilla, persistent-after-activation, and always-on modes.
- Creative-only toggle (`B`) and launch-toast preference (`N`).
- Ground-level Sneak camera stabilization during assisted flight.
- When enabled, creative flight inertia stops immediately after movement, jump, or sneak input is released.
- When disabled, vanilla creative flight behavior remains unchanged.

This branch contains the Fabric beta.5 release candidate for Minecraft `26.2`. Fabric beta.4 remains the public version until this candidate completes its exact-JAR live and publication gates.
